# Support

Use the repository's issue forms for reproducible bugs, component proposals,
accessibility problems, and documentation changes.

Before opening an issue:

1. Search existing issues.
2. Reproduce the problem with a supported Flutter version.
3. Reduce it to a minimal example when possible.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md), not the public
issue tracker. General Flutter support questions belong in Flutter community
channels unless they involve Nemo UI behavior.
